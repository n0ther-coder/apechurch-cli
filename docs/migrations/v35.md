# CLI 35 migration

CLI 35 introduces two runtime changes for integration authors.

| Earlier behavior | Current behavior |
| --- | --- |
| A rational monetary threshold could retain a fraction of wei during comparison or shortfall reporting. | Truncate the calculated threshold toward zero to whole wei first. Then apply the configured strategy difference precision. `none` and `18` distinguish every wei in the shared comparator. Shortfalls contain at most 18 APE decimal places. |
| A watcher retried child configuration errors like other nonzero exits. | Configuration failures use exit code 78 and stop the watcher after cleaning process state and releasing its lock. Pending code 75 keeps its reconciliation behavior. |

Bots should identify configuration failures with `error.code = 'BOT_USAGE_ERROR'`
or `error.botUsageError = true`. Preserve that classification when wrapping
nested errors. Review callers that previously assumed every validation failure
returned 1 or that every child exit would be retried.

Keep monetary coverage sizing, analysis and diagnostics in whole wei. Retain
minimum-stake, affordability and accounting checks. Dimensionless multipliers,
probabilities and percentages are unaffected by the monetary resolution rule.
